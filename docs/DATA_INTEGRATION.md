# 真实数据接入

公开示例用于验证代码接口。服务器上的原始数据、SOURCE监督、原始划分和权重不随本仓库发布。
此移植版尚无可直接对任意数据运行的真实训练CLI，也没有把未训练模型作为科学可用模型。

## 外部模型输入

- 逐湖几何：独立来源的深度边界、面面积、原生单元体积与参考水面。单元储量使用原生体积；不以面面积积分替换它。
- CORE9：气温、露点、东西/南北风、气压、短波、长波、降水和降雪。瞬时量与原生累积量分别保留时钟、SI单位和支撑区间。
- token的start/end/available采用相对于窗口起点的真实秒；UTC起点为整数纳秒。
- 训练标准化与初态参考来自冻结SOURCE外部统计。公开工厂的7°C参考仅为明确的制造/外部候选，不能替代实际先验。
- 观测标签保存在独立loss/readout通道，不进入batch、几何构网格或初始化。

## 当前边界

真实运行原入口`RealExterior`依赖已审计的公开几何、气象流、driver policy、TRAIN先验、输入ledger和receipt。
它绑定特定版本与哈希，并非通用CSV导入器。完整原执行环境还包含canonical SOURCE、共享时钟观测算子和显式预算。
移植后的库保留模型与物理组件，未把这些私有路径和数据硬编码成公开默认值。

新数据接入顺序：

1. 保留原TRAIN/validation/test角色及同湖别名隔离，独立生成数据manifest和SHA。
2. 明确原始单位、瞬时/日均/事件均/未知时钟、观测深度基准与QA；缺失保留pending。
3. 用SOURCE外部统计冻结模型normalization；在SOURCE内核对原生物理定义域、完整前反向与固定FD。
4. 用独立新目录、新预算重训，冻结代码、数据、读出与权重后评分。目标标签不参与选择。
5. 报告原分母、成功支持、失败及未评价状态；软件或制造场景通过不等于真实精度通过。

真实依赖缺失时保持明确BLOCKED；不以制造观测或热源替代。没有合格盐化学、卫星或输运支持，
就不宣称已完成这些通道。
